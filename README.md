# Royal Drive Gallery

## Project Overview

Royal Drive Gallery is a Car Rental Agency database project developed using Microsoft Access as part of a university team project. The project focuses on organizing car rental-related data through a structured database design.

## Technologies Used

- Microsoft Access
- Relational Database Design
- Database Queries
- Forms and Data Management

## Key Features

- **Tables:** Organize and store car rental-related data.
- **Relationships:** Define connections between related tables.
- **Queries:** Retrieve and work with data stored in the database.
- **Forms:** Provide an interface for interacting with database records.

## Project Objectives

- Design a structured database for a car rental agency.
- Establish relationships between related data.
- Use queries to retrieve and manage information.
- Create forms to interact with database records.
- Apply database design concepts in a practical project.

## Teamwork and Contributions

This project was developed collaboratively as part of a university team project.

The team worked on designing and implementing a Microsoft Access database for a car rental agency, including tables, relationships, queries, and forms.

## Project Files

- **Royal Drive Gallery (`.accdb`):** The Microsoft Access database containing the tables, relationships, queries, and forms.

## How to Open the Project

1. Download the `.accdb` file from this repository.
2. Open the file using Microsoft Access.
3. Explore the tables, relationships, queries, and forms.

## Notes

This project was developed for educational purposes to practice relational database design and database management using Microsoft Access as part of a collaborative team effort.
